Before performing any upgrade please make sure to [backup your current installation of AppVeyor Server](/docs/server/maintenance/#backuprestore-appveyor-server)!

This release contains an important security fix and we recommend all AppVeyor Server users to upgrade.

Security:

* Fixed broken access control in temporary artifact download links. A download link token is now bound to the specific build job and artifact it was issued for and can't be used to download other artifacts. Download links issued before the upgrade stop working.

What's new:

* Fixed "Error adding SSH key to GitHub repository" when adding a new project: AppVeyor now generates 4096-bit RSA deploy keys as GitHub rejects keys shorter than 3072 bits.
* Azure DevOps repositories can be cloned with Personal Access Token (PAT) authentication.
* AppVeyor Server runs on .NET 6.
* 'Enable secure variables in all Pull Requests' setting for Gitea repositories.
* Fixed webhooks for generic Git and Beanstalk repositories on Linux and macOS.
* Build agents on AWS EC2 support Instance Metadata Service Version 2 (IMDSv2).
* Fixed Docker server version detection in Docker build cloud.
* Full details of unexpected errors are displayed in the build log.

Windows, Linux and macOS releases updated. [Follow this guide](/docs/server/maintenance/#upgrading-appveyor-server) to upgrade your AppVeyor Server installation to the latest version.
